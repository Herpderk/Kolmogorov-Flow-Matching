# Kolmogorov Flow Matching

Dataset: https://huggingface.co/datasets/ayz2/temporal_pdes/tree/main

Reference: https://arxiv.org/abs/2309.01745v3

# Setup
Make sure the uv package manager is installed. Installation instructions: https://docs.astral.sh/uv/getting-started/installation/.
## To set up this project's dependencies and virtual environment, simply run:
```uv sync```

Training and benchmarking code can be found /notebooks/. Make sure to run them using the virtual environment's interpreter.
